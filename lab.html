اللغات المتاحة
المحرر يحتوي أمثلة للغات كثيرة. HTML وCSS وJavaScript يمكن معاينتها مباشرة هنا. لتشغيل Python وC++ وJava وغيرها، يلزم ربط خدمة تشغيل أكواد خارجية آمنة.
داخل المتصفح
HTML · CSS · JavaScript
تعمل مباشرة
عبر خدمة خارجية
Python · C/C++ · Java · C# · PHP · Go · Rust وغيرها حسب مزود الخدمة.
تحتاج إعداد
خطوات الربط باختصار
  1. أنشئ خدمة تشغيل مثل Judge0 لدى مزوّد موثوق.
  2. أنشئ Cloudflare Worker ليكون وسيطًا آمنًا بين الموقع والخدمة.
  3. ضع رابط الـ Worker في ملف lab.js داخل RUNNER_URL.
  4. احتفظ بمفتاح API داخل إعدادات Worker السرية فقط، وليس داخل ملفات الموقع العامة.
ملفات GitHub Pages ثابتة؛ لا يمكنها تشغيل كل لغات البرمجة على الخادم وحدها.
